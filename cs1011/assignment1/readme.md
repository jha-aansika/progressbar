# Q1 - PROBLEM SOLVING

_Flow of actions: Problem Statement -> Problem Analysis -> Algorithm -> Pseudocode -> Flowchart  -> C Program -> Compilation -> Testing -> Debugging._

**Problem statement**: A program that reads three integers and displays the largest integer


**Problem analysis:**:
                    
                       1. _Input_: 3 variables

                       2. _Output_: Single largest integer
                       
                       3. _Logic used_: if - else if - else; multivariable                                conditional branching
                       
**Algorithm**: 

               Step 1. Start

               Step 2. Input 3 variables
               
               Step 3. Read the 3 values
               
               Step 4. Check if A>B and A>C, set Largest = A and go to step 6.  If no, go to step 5.
               
               Step 5. Else if B>C, set Largest = B. Else, Set Largest = C.
               
               Step 6. Display the evaluated Largest value.
               
               Step 7. Stop

**Psuedocode**: ```
                
                BEGIN

                Input A, B, C
                
                If A>B and A>C THEN
                
                  LARGEST = A
                  
                ELSE IF B>C THEN
                
                  LARGEST = B
                  
                ELSE
                
                  LARGEST = C
                  
                DISPLAY LARGEST
                
                END
                ```
